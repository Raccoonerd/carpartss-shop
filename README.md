# Car Parts Store

A desktop application for managing a car parts shop, built with WPF, .NET, Entity Framework Core, and Microsoft SQL Server.

## Overview

Car Parts Store is a Windows desktop application designed to handle the day-to-day operations of a car parts shop. It provides a clean Material Design interface for managing inventory, customers, sales, and order history.

## Features

- **Parts management** — full CRUD operations on the parts catalog with category info, stock tracking, and search by name
- **Categories** — quickly add new categories directly from the parts form via a popup dialog
- **Customers** — manage business customers with company name and unique NIP (tax ID) validation
- **Sales** — build a shopping cart, select customer, validate stock availability in real time, and finalize orders with automatic stock deduction
- **Order history** — browse past orders with their line items, filter by customer and date range
- **Material Design UI** — modern dark-themed interface with animated cards, icons, and responsive forms

## Tech Stack

- **WPF (.NET)** — desktop UI framework
- **C#** — primary language
- **CommunityToolkit.Mvvm** — MVVM framework with source generators (`[ObservableProperty]`, `[RelayCommand]`)
- **Entity Framework Core** — ORM with database-first approach (scaffolded from existing schema)
- **Microsoft SQL Server (LocalDB)** — database engine
- **MaterialDesignThemes** — UI component library by James Willock (ButchersBoy)

## Architecture

The project follows the **MVVM (Model-View-ViewModel) pattern**:

```
Views (XAML)  ◄──── binding/commands ────►  ViewModels  ────►  DbContext  ────►  SQL Server
```

- **Models/** — entity classes generated by `Scaffold-DbContext` from the database schema
- **ViewModels/** — business logic, observable properties, and relay commands; no direct UI references
- **Views/** — XAML user controls and windows; minimal code-behind
- **Views/Dialogs/** — reusable Material dialogs (Info, Confirm, Error)
- **Services/** — application services such as `DialogService`

A `MainViewModel` acts as a shell, swapping the active `UserControl` (Parts, Customers, Sales, Orders) in the main content area without opening new windows.

## Database Schema

Five tables connected with foreign keys:

| Table | Purpose |
|---|---|
| `Categories` | Part categories (Brakes, Filters, Oils, etc.) |
| `Parts` | Catalog of parts with name, catalog number, price, stock quantity |
| `Customers` | Business customers with company name and unique NIP |
| `Orders` | Sale headers with timestamp and customer reference |
| `OrderItems` | Line items linking orders to parts with quantity and unit price |

Constraints in place:
- `CHECK` constraints prevent negative prices and stock
- `UNIQUE` constraint on customer NIP
- Foreign keys enforce referential integrity
- `IDENTITY` columns for auto-generated primary keys
- Default `GETDATE()` for order timestamps

- SQL Server Management Studio (SSMS) for database setup

## Setup

### 1. Create the database

Open SSMS and connect to your SQL Server instance (`(localdb)\MSSQLLocalDB` or `.\SQLEXPRESS`). Run the SQL script from the repository to create the `CarPartsStore` database with all tables, constraints, and sample data.

### 2. Update the connection string

Open the generated `CarPartsStoreContext.cs` in the `Models/` folder and verify the connection string matches your server:

```
Server=(localdb)\MSSQLLocalDB;Database=CarPartsStore;Trusted_Connection=True;TrustServerCertificate=True;
```

### 3. Build and run

Open the solution in Visual Studio and press `F5`. The application launches on the Sales screen by default. If You downloaded release, then just start `.exe` file after creating database form script.

### 4. Regenerating entities (optional)

If you modify the database schema, regenerate entity classes from the Package Manager Console:

```
Scaffold-DbContext "Server=(localdb)\MSSQLLocalDB;Database=CarPartsStore;Trusted_Connection=True;TrustServerCertificate=True;" Microsoft.EntityFrameworkCore.SqlServer -OutputDir Models -Force
```

## Usage

### Adding a part

1. Open **Parts** from the side menu
2. Fill in the form (name, catalog number, category, price, stock)
3. Use the **+** button next to the category dropdown to create a new category on the fly
4. Click **ADD**

### Making a sale

1. Open **Sales**
2. Select a customer from the dropdown
3. Search for a part, set quantity, click **ADD TO CART**
4. Review the cart and total amount
5. Click **FINALIZE ORDER** — stock is automatically reduced and the order is saved

### Browsing orders

1. Open **Orders**
2. Filter by customer, start date, or end date
3. Click an order in the list to see its line items in the panel on the right

## Notes

- This project is a school assignment focused on demonstrating MVVM, EF Core, and Material Design in WPF.
- Stock levels are validated both when adding to cart and again at order finalization to prevent overselling.
- Unit prices are frozen at the moment of sale (copied into `OrderItems.UnitPrice`), so changing a part's price later does not affect historical orders.
